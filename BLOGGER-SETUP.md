# ToolNest setup

This package contains 90 individual SEO-friendly tool pages, responsive CSS, PWA manifest/service worker, and About/Privacy/Contact/Disclaimer pages.

Blogger note: Blogger is not a normal static-file host, so you cannot upload this folder as-is and automatically get 90 Blogger Pages. Use these pages as the source for Blogger Pages/Posts or use the package on a static HTTPS host. For a true installable PWA, the static package is the cleaner route.

Ad placeholders are labelled ADVERTISEMENT. Replace them only with approved responsive ad code. Keep download controls clearly separated from ads. Google says ads must not be made to look like navigation/download links and recommends clean, uncluttered responsive layouts.

Before publishing: replace placeholder contact text, add your real domain/canonical URLs, test every tool, add your favicon, and add required privacy/consent disclosures for your ad/analytics setup.
